# Aoda Zhang — Personal Site

A personal site about the intersection of software, curiosity, and life. It brings together my engineering practice, ongoing work on PawHaven, and the experiences that keep me curious beyond the screen.

**Live site:** https://aoda.vercel.app/

## Engineering focus

- **Frontend engineering:** React, TypeScript, frontend architecture, component systems, and accessible UI.
- **Full-stack development:** Node.js, NestJS, API design, and service integration.
- **AI engineering:** LLM-powered workflows, agent harnesses, and developer tooling.

## Featured project

[PawHaven](https://github.com/aoda-zhang/PawHaven-FullStack-React-NodeJS) is a rescue-animal platform in active development, bringing product design, full-stack architecture, and AI-assisted engineering together around a practical social purpose.

## Tech stack

- Next.js App Router
- React 19 and TypeScript
- Tailwind CSS
- Framer Motion
- React Icons

## Local development

Requirements: Node.js and pnpm.

```bash
pnpm install
pnpm dev
```

Open http://localhost:3000.

## Production build

```bash
pnpm build
pnpm start
```

The site is deployed on Vercel.
